- 🎓 Software Engineering student at **ESPRIT** (evening program), Bachelor in Computer Science & Multimedia from **ISIMS**.
- 🧠 Learning in public: agents with tool calling and **MCP**, structured output, **LLM evaluation**, cost control and prompt-injection defense.
- 🌍 Tunis, Tunisia · Arabic (native) · English (B2) · French (B2)
